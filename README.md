# MANNY® — Independent Digital Studio

Personal portfolio built with Next.js, React, TypeScript and custom CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Projects and screenshots

Project links and statuses are maintained in `src/app/page.tsx`. The Mamori and Strata preview images use live-page captures from thum.io; they are not generated mockups. Update the screenshot URLs or replace them with locally stored captures as needed.

## Deploy

The project is deployed on Vercel. The GitHub repository is the source archive for the portfolio.
